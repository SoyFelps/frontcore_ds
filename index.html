Logo & icons

For use on a light background, we generated the logo-dark.png variant (same icon, text in --title). Layout

          
App frame (FrontCore-specific convention)

          
Unlike the other tokens (reusable in any project), this is a convention of this prototype: every screen is rendered inside a fixed 1366×768px frame, centered over a neutral gray background — simulating a "device" and avoiding any resizing with the browser window.

        

        
📌Use this pattern only if the new project also needs fixed-size screens (e.g., prototype presentations). It is not recommended for real responsive products.

        

          

            

              

                

                

                  

                  

                    

                  

                

              

            

          

          

            
            
body{
  margin:0; display:flex; justify-content:center; align-items:flex-start;
  background:var(--backdrop); /* #c8c8c8 */
}
.frame{
  width:1366px; height:768px; flex-shrink:0;
  background:var(--background); overflow:hidden;
  display:flex; flex-direction:column;
  box-shadow:var(--shadow-xl); /* 0 0 24px rgba(0,0,0,0.25) */
}
